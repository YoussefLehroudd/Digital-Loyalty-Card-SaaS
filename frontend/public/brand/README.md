# Brand Assets

Put the app brand images in this folder.

Recommended files:

- `logo.png`: main full logo for the site header and marketing sections.
- `icon.png`: square app icon, ideally 512x512, for compact UI spots.
- `favicon.png`: browser favicon, ideally 32x32 or 48x48.
- `apple-touch-icon.png`: mobile home-screen icon, ideally 180x180.
- `og-image.png`: social preview image, ideally 1200x630.

Public URLs after deploy:

- `/brand/logo.png`
- `/brand/icon.png`
- `/brand/favicon.png`
- `/brand/apple-touch-icon.png`
- `/brand/og-image.png`
